卡家漫画汉化安装教程
2025/9/17
1.确保你拥有了uhc阅读器本体和assets包，可以正常打开阅读器
2.在我的网站下载CNassets文件夹和CN-HS.js文件
3.你下载uhc的目录里找到Asset_Pack\mods，在mods文件夹里放入CH-HS.js文件，和CNassets文件夹（和里面的东西）
4.打开阅读器，在上面的栏里找到SETTINGS点进去
5.向下拉找到Mod Settings，把CN assets和HS CN translation拖动到右边Active，重启程序
